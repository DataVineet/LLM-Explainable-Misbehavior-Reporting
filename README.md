# Project Objective

This research aims to develop an Explainable Artificial Intelligence (XAI) framework for vehicular misbehavior detection using the VeReMi dataset.

The framework combines:

- Machine Learning Models
- Explainable AI (SHAP)
- Large Language Models (LLMs)
- Automated Misbehavior Reporting

The final objective is to build an end-to-end reproducible pipeline capable of detecting malicious vehicular messages while providing interpretable explanations suitable for researchers and cybersecurity analysts.
